# 개미레이더 — 주식 투자 도우미

국내·해외 우량주·성장 후보를 **이유와 함께** 보고, **매집봉**을 스캔하며, **매수·매도 타이밍 알림**을 받을 수 있는 교육용 웹 앱입니다.

## 기능

- **기법 학습**: 가치투자, 매집봉, 이평선, RSI, 돌파, 분할매수, 배당, 리스크 관리
- **매집봉 스캐너**: 거래량 배수 · 아랫꼬리 · 종가 회복 · 20일선 지지 점수화
- **종목 분석**: KR/US 워치리스트 + 성장 동력·리스크·타이밍 코멘트 + 차트
- **알림**: 목표가/지지가/매집봉/RSI 조건 + 브라우저 Notification

> 차트·시세는 **교육용 시드 데이터**입니다. 투자 권유가 아니며 실제 매매 전 공시·시세를 확인하세요.

## 실행

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```
